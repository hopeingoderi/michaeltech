Files and Folders

In this lesson, students learn how to create, rename, move, and organize files and folders in a simple and confident way.

Learning goals

  • Understand the difference between files and folders
  • Create and rename folders
  • Move and copy files
  • Organize documents clearly

Practice task

Create a folder called My Documents. Inside it, create three subfolders: School, Work, and Personal.

Lesson outline

  1. Introduction to computers
  2. Keyboard and mouse basics
  3. Files and folders
  4. Operating system basics
